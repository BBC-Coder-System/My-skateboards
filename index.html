Strip setup
Tell the controller how many LEDs your strip has. If the number is wrong, moving effects stop early, stretch, or jump. The controller stores this, so you only need to do it once.
A 2 m strip usually has 60 (30/m), 120 (60/m) or 288 (144/m) LEDs. Count the LEDs in 10 cm and multiply by 20. Test sends a single red tail down the strip: with the right count it runs smoothly from one end to the other.
