Your strip
Strip setup
Tell the controller how many LEDs your strip has. If the number is wrong, moving effects stop early, stretch, or jump. The controller stores this, so you only need to do it once.
A 2 m strip usually has 60 (30/m), 120 (60/m) or 288 (144/m) LEDs. Count the LEDs in 10 cm and multiply by 20. Test sends a single red tail down the strip: with the right count it runs smoothly from one end to the other.
Wire order

Music speed
Music update rate
30/s
How many colour updates per second music effects send. The official app sends its music colours far faster than normal ones, so higher usually lands beats better and looks smoother. If the strip lags or drops, lower it (the app lowers it by itself after repeated write timeouts).
Fix problems (advanced)
Only change these if something misbehaves, or if Claude asks you to.
15/s
How many colour updates per second the app sends. Lower is more stable, higher is smoother. The app lowers it automatically if the strip keeps dropping the connection.
120 ms
(Also called "dimming gap".) Minimum time between brightness and speed commands (effects that dim or pulse a built-in effect). The strip digests these slowly; if they pile up, pulses land late. Raise it if pulses still drift off-beat, lower it for smoother fades. A beat's own pulse ignores the gap.
